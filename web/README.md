# 听 · 酷狗音乐

本地酷狗状态展示页，通过已安装的 `kugo-mcp` 同步当前歌曲、封面、播放状态、模式和每日推荐。

1. 先按照仓库根目录的 README 安装依赖（创建 `.venv` 并运行 `npm ci`）。
2. 双击 `start.bat`，保留打开的窗口。网页服务会先启动 MCP；若酷狗尚未运行，会通过 MCP 的启动命令自动打开酷狗。
3. 浏览器访问 <http://127.0.0.1:8765>，在酷狗中打开“推荐”页。停止时关闭服务窗口。

如果酷狗已经以普通方式运行且调试连接不可用，网页会提示你完全退出酷狗后点击“重新连接”。程序不会强制结束正在播放的酷狗；如果已存在可用调试连接，则直接复用。

页面打开或刷新时会重新读取酷狗和每日推荐；推荐在此之后不会定时刷新。浏览时约每 2.5 秒读取一次歌曲与位置，没有页面访问时降低读取频率。歌曲变化时加载歌词和封面，并根据酷狗进度显示当前一句歌词。进度读取使用客户端私有接口，当前版本的时间单位根据实测推断，版本变化后可能需要调整；没有时间戳或进度时会显示提示。点击每日推荐会让酷狗从对应曲目开始播放，并替换当前临时队列。默认使用仓库根目录的 MCP 服务；如需使用其他兼容的 MCP 服务目录，可设置 `KUGO_MCP_HOME`。

播放请求可能被客户端执行但返回验证超时，页面会提示并在随后重新读取状态。

后续开发桌面组件可参考 [本地接口文档](API.md)，其中列出了状态、主动刷新和播放控制接口。
